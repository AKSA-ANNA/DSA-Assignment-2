# Final Conclusion

The hospital priority queue was successfully implemented using a Max Heap.

The Max Heap ensures that the patient with the highest severity score
always remains at the root, allowing efficient access to the
highest-priority patient.

Heap Sort and Quick Sort were also implemented and compared. Heap Sort
provides O(n log n) time complexity in the best, average, and worst
cases, while Quick Sort has an average complexity of O(n log n) but can
take O(n²) in the worst case.

For the given data, both sorting algorithms produced the sorted
severity scores:

30 45 50 65 72 85 90

Overall, the Max Heap is an efficient and suitable data structure for
managing hospital patient priorities.
